## 如何使用

- `.txt` 保留当时保存的 Prompt 文本，包括首次生成、表情／动作／服装差分、面容对齐和清理杂纹等修订，未重新改写成事后总结。
- 很多 Prompt 是针对参考图的局部编辑指令。使用时需要结合对应人物基准和上一版图像，仅复制文字无法保证复现相同人物或画面。
- [机器可读目录](catalog.json) 记录 Prompt 校验值、参考图标识、生成图标识和当前用途。参考图标识用于辨认素材，不代表所有历史参考图均已公开。
- 历史稿包含尚未采用或被替代的设计。制作新章节请优先参照当前采用版，并按项目贡献指南先在 Issue 中确认人物时期与场景。
- 未保存的原始 Prompt 与非生成式修图不会补写成“原始 Prompt”；具体例外见当前对照表。

贡献新的 AI 图像时，请一并提交生成与修订 Prompt、图片编号／版本、参考图来源及用途；延用既有角色时应保留其已确认特征。
