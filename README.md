# 想要变成鹰的鱼

基于 WebGAL 制作的中文视觉小说序章试玩，提供本地预览与 GitHub Pages 发布配置。

## 游玩

[在线试玩](https://verapyuyi.github.io/fish-wants-to-be-a-bird/)。请通过网站地址游玩，不要直接打开 `web/index.html`。

点击或按空格推进文本；底栏提供回想、自动、快进、存读档和选项。存档保存于当前浏览器和站点地址中；清除站点数据或更换浏览器会影响本机存档。此次 r4 更新从头开始，使用独立存档，先前版本的数据不会被删除或覆盖。

## 快进背景同步（2026-10-16）

快进间隔由50毫秒调整到150毫秒。遇到尚未加载完成的背景时，会等待画面就绪后继续。已缓存的图片立即切换；加载失败不会让快进永久卡住。修复保留切场防闪黑、原有剧情、图片、音频和存档。

## 存档修复（2026-10-16）

剧情结束、跳过视频或完整播放视频均保留进度。首页“继续游戏”恢复结束前的剧情；“读取存档”中的“读取快速存档”恢复手动快速保存的位置，普通编号存档独立保留。视频播放期间不会覆盖剧情进度，读档会停止自动和快进。旧版已清空的自动进度仅在仍有手动快速存档时可以回退恢复；不会伪造或重建已丢失的分支选择。存档标识与原版一致。

## 结尾视频（2026-10-16）

进入剧情后会在后台提前缓存完整视频 v10，故事结束直接在整个游戏画面播放，不显示播放器框、进度条或按钮；点击画面即可跳过。完整观看后，“读取存档”页面中的“重播结尾视频”解锁，点击跳过不会解锁。解锁记录保存在同一浏览器、同一站点，独立于剧情存档。视频音量沿用游戏主音量和音乐音量；浏览器阻止播放时，按画面提示轻触播放。剧情结尾播放完成返回首页；从读取存档重播则返回该页面。开始游戏、继续、读档及重播会尝试进入全屏，也可用游戏工具栏切换全屏；浏览器不支持时保持窗口显示。此前剧情、图片、v10 音视频与 r4 存档标识保持不变。

## 切场闪黑修复（2026-10-16）

新背景准备完成后才替换旧背景，避免加载间隙出现黑底。快进、回退与读档只显示最新请求的画面；未能加载时保留上一画面并提供重试提示。五处过渡叙述延续上一幅图，避免突然清空背景。对白、美术、配乐及现有存档保留。

## 快进修复（2026-10-16）

刷新后，“快进”默认跳过全部文本，遇到选择会等待操作。再次点击可停止；按住 Ctrl 可临时快进。旧版的“已读”默认设置仅迁移一次，存档和其他设置保留。之后在“选项 → 系统 → 快进模式”选回“已读”会持续保存，按钮也会标为“快进（已读）”。

## 本次更新（r4 · 2026-10-11）

本次修订调整检票、登车、进店、房东出场与整理小屋的画面顺序，去掉提前闪出的画面。配乐同曲跨场保持进度，换曲先淡出再淡入；保留已通过的曲目和夜宿音乐。

查看修订内容请刷新后从“开始游戏”进入；旧存档可能包含原剧本快照。本次保留 r4 存档空间。

## 本地预览

使用 Python 3 在仓库根目录运行 `python3 serve.py --open`，然后保留该窗口。资源未载入时，使用页面中的“重新载入”。

## 发布内容与许可

公开仓库包含运行所需的 `web/`、说明、启动与检查工具及 Pages 工作流。原生剧本为 `web/game/scene/start.txt`，界面样式源码在 `web/game/template/`。完整原作、内部记录、制作原料、旧图、交付压缩包和临时文件均不在公开导出范围内。

引擎、字体、图像和音频的署名与适用许可在 `web/LICENSE-*` 和 `web/CREDITS-*` 中。配乐过渡的引擎修改源码及重现方法位于 `web/engine-source/r4-bgm/`。
